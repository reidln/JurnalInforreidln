## 1. Membandingkan Dua Bilangan

![](/images/journalLogs/2026-09-15_flow01.jpg)

Code:
![](/images/journalLogs/2026-09-15_code01.jpg)

> Code ini meminta user untuk memasukkan dua angka. Lalu `if a > b:` akan mengecek apakah angka pertama lebih besar dari angka kedua. Jika iya, maka akan mengeluarkan angka pertama.
> Jika tidak, `elif b > a:` akan mengecek apakah angka kedua lebih besar. Jika iya, maka akan mengeluarkan angka kedua.
> Jika kedua kondisi tersebut tidak terpenuhi, berarti kedua angka memiliki nilai yang sama dan `else:` akan mengeluarkan `"kedua bilangan sama"`.

Code:
![](/images/journalLogs/2026-09-15_code02.jpg)

> Code ini meminta user untuk memasukkan sebuah huruf. Lalu `if huruf in ['a','e','i','o','u']:` akan mengecek apakah huruf tersebut termasuk huruf vokal. Jika iya, maka akan mengeluarkan `"Ini adalah huruf vokal"`.
> Jika tidak, `elif` akan mengecek apakah huruf tersebut merupakan huruf alfabet. Jika iya, maka akan mengeluarkan `"Ini adalah huruf konsonan"`.
> Jika kedua kondisi tersebut tidak terpenuhi, maka `else:` akan mengeluarkan `"Bukan huruf alfabet"`.

## 3. Tahun Kabisat

![](/images/journalLogs/2026-09-15_flow03.jpg)

Code:
![](/images/journalLogs/2026-09-15_code03.jpg)

> Code ini meminta user untuk memasukkan angka tahun. Lalu tahun akan dicek menggunakan beberapa kondisi.
> Jika `tahun % 400 == 0`, maka tahun tersebut merupakan tahun kabisat.
> Jika tidak, `elif tahun % 100 == 0:` akan mengecek apakah tahun tersebut habis dibagi 100. Jika iya, maka bukan tahun kabisat.
> Jika tidak, `elif tahun % 4 == 0:` akan mengecek apakah tahun tersebut habis dibagi 4. Jika iya, maka merupakan tahun kabisat.
> Jika semua kondisi tidak terpenuhi, maka `else:` akan mengeluarkan bahwa tahun tersebut bukan tahun kabisat.
