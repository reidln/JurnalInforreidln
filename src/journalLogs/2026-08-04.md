Menggunakan fungsi `print()` untuk mengeluarkan string dan menggunakan lebih dari satu argumen.
![](/images/journalLogs/2026-08-04_code01.png)
Output akan menjadi:
```
Smart_Millenials_Awesome_Visioner_Outstanding***SMAVO
```
> Code ini mengeluarkan setiap string argumen dalam fungsi `print()` tersebut. Setiap string tersebut dipisah oleh `_` dan diakhiri oleh `***`.
> Ketika code `print("SMAVO")` jalan, output tersebut tidak berada di baris selanjutnya. Ini dikarenakan nilai `end=` adalah `\n` dengan biasanya.
> Jika tidak ada parameter `end=` maka akan menjadi `\n`.
>

Menggunakan parameter `sep` (separate) dalam fungsi `print()`
![](/images/journalLogs/2026-08-04_code02.png)
Output akan menjadi:
```
Smart
Millenials
Awesome
Visioner
Outstanding
```
> Ini juga menggunakan `sep=`. Tetapi, di sini `sep="\n"`. Maka, setiap argumen akan terus di baris baru ketika `print()` berjalan.
