## 1. Pengecekan Nilai x

Minta user untuk memasukkan nilai `x`. Jika nilai `x < 70`, tampilkan `"Gagal"`. Kemudian selalu tampilkan `"akhir dari program"`.

**Flowchart:**
![](/images/journalLogs/2026-09-03_flow01.jpg)

**Code:**
![](/images/journalLogs/2026-09-03_code01.jpg)

> Code ini meminta masukan angka `x` dari pengguna. Pernyataan `if x < 70:` akan mengevaluasi apakah nilai yang dimasukkan kurang dari 70. Jika bernilai benar (`True`), maka string `"Gagal"` akan dicetak. Setelah percabangan `if` selesai, baris `print("akhir dari program")` akan selalu dijalankan karena berada di luar instruksi blok `if`.
