## 1. Penentuan Harga Tiket

![](/images/journalLogs/2026-09-10_flow01.jpg)

Code:
![](/images/journalLogs/2026-09-10_code01.jpg)

> Meminta input `usia` dan `hari`. Jika `usia < 12`, program mengecek hari: jika Sabtu atau Minggu harga tiket Rp10.000, sedangkan hari kerja Rp5.000. Jika `usia >= 12`, program mengecek hari lagi: jika Sabtu atau Minggu harga tiket Rp20.000, sedangkan hari kerja Rp15.000.

---

## 2. Perhitungan Potongan Gaji Karyawan

![](/images/journalLogs/2026-09-10_flow02.jpg)

Code:
![](/images/journalLogs/2026-09-10_code02.jpg)

> Meminta input `status` karyawan (Tetap atau Kontrak) dan `terlambat`. Untuk karyawan Tetap: jika terlambat > 5 jam potongan 10%, 1-5 jam potongan 5%, dan 0 jam tidak ada potongan. Untuk karyawan Kontrak: jika terlambat > 3 jam potongan 15%, 1-3 jam potongan 7%, dan 0 jam tidak ada potongan.

---

## 3. Perhitungan Tarif Parkir

![](/images/journalLogs/2026-09-10_flow03.jpg)

Code:
![](/images/journalLogs/2026-09-10_code03.jpg)

> Meminta input `jenis` (Motor atau Mobil) dan `lama`. Untuk Motor: 2 jam pertama Rp2.000, jam berikutnya ditambah Rp1.000 per jam. Untuk Mobil: 2 jam pertama Rp5.000, jam berikutnya ditambah Rp2.000 per jam.
