## 1. Perhitungan Diskon Belanja

Flowchart:
![](/images/journalLogs/2026-09-08_flow01.jpg)

Code:
![](/images/journalLogs/2026-09-08_code01.jpg)

> Meminta masukkan total belanja pengguna. Menggunakan kondisi `if-else`: jika total belanja lebih dari Rp500.000,00 maka pengguna mendapat diskon 10%. Jika tidak (kurang dari atau sama dengan Rp500.000,00), pengguna mendapat diskon 5%. Total bayar dihitung dari total belanja dikurangi diskon.

## 2. Cek Bilangan Genap atau Ganjil

Flowchart:
![](/images/journalLogs/2026-09-08_flow02.jpg)

Code:
![](/images/journalLogs/2026-09-08_code02.jpg)

> Meminta pengguna memasukkan sebuah bilangan bulat. Menggunakan operator modulo `%` untuk memeriksa sisa bagi dengan 2. Jika `bilangan % 2 == 0`, maka program menampilkan bahwa bilangan tersebut adalah genap. Jika tidak, program menampilkan bahwa bilangan tersebut ganjil.

---

## 3. Cek Kelayakan Pembuatan KTP

Flowchart:
![](/images/journalLogs/2026-09-08_flow03.jpg)

Code:
![](/images/journalLogs/2026-09-08_code03.jpg)

> Meminta pengguna memasukkan usia. Jika `usia >= 17`, program menampilkan pesan bahwa pengguna sudah cukup umur untuk membuat KTP. Jika `usia < 17`, program menampilkan pesan bahwa pengguna belum cukup umur.
