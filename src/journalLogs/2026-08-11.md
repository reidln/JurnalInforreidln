## 1. Operator Penjumlahan
![](/images/journalLogs/2026-08-11_prob01.jpg)

Output:
```
5
5.0
5.0
5.0
-1
-1.0
-1.0
```

> - Semua baris tidak menghasilkan output yang sama.
>   * Baris 1 mengeluarkan `5` dalam **int**.
>   * Baris 2-4 mengeluarkan `5.0` dalam **float**.
>   * Baris 5 mengeluarkan `-1` karena penjumlahan dengan negatif akan menjadi pengurangan.
>   * Baris 6-7 sama dengan baris 5 tetapi dalam bentuk **float**. 
> - Fungsi tanda `#` adalah untuk menandakan bahwa barisan tersebut tidak untuk dibaca sebagai kode dari program. Digunakan di depan huruf-huruf yang akan diabaikan.
> - Tanda `.` setelah angka menandakan bahwa angka tersebut merupakan tipe data **float**. Dengan adanya tanda `.` dan tidak ada angka lagi setelahnya, berarti angka desimalnya tidak ada, tetapi akan dibaca sebagai `0` secara otomatis.

## 4. Operator Pembagian
![](/images/journalLogs/2026-08-11_prob04.jpg)

Output:
```
2.0
2.0
2.0
2.0
```

> - Semua baris menghasilkan output yang sama. Tipe datanya adalah **float**.
>   Karena pembagian antara salah satu dari bilangannya adalah **float** maupun keduanya **integer**, ada kemungkinan untuk mengeluarkan nilai desimal. Seperti: `3 / 2 = 1.5`

## 5. Operator Pembagian Floor
![](/images/journalLogs/2026-08-11_prob05.jpg)

Output:
```
1
1.0
1.0
1.0
-2.0
-2
```

> - Fungsi operator `//` berfungsi sama dengan operator `/` yang menggunakan fungsi `floor()`. Sama dengan beberapa operator sebelumnya,:
>   - Jika keduanya **integer** maka akan mengeluarkan hasil dengan tipe data **integer**.
>   - Jika salah satunya merupakan **float** maka akan mengeluarkan **float**, namun angka desimalnya tetap bernilai `0`.

Output:
```

0
```

> - Fungsi operator modulo (sisa bagi) berfungsi untuk mengeluarkan sisa dari operasi `a` membagi `b`.
>   - Dalam barisan ke-1 hasilnya adalah `1` karena `3 * 3` adalah `9` yang merupakan nilai tertinggi dari kelipatan 3 sebelum melebihi `10`.

## 8. Bindings
![](/images/journalLogs/2026-08-11_prob08.jpg)

Output:
```
1
256
```

> - Pada baris ke-1 akan menjalankan `9 % 6` yaitu `3` lalu `3 % 2` yaitu `1`.
> - Pada baris ke-2 akan menjalankan `2 ** 3` yaitu `8` lalu `2 ** 8` yaitu `256`. 
> - Operator ini akan dijalankan terlebih dahulu sebelum operator lain seperti `+`, `-`, `*`, `/`, dan sebagainya.
> - Operator yang lain dijalankan dari kiri ke kanan.

## 10. Variabel
![](/images/journalLogs/2026-08-11_prob10.jpg)

Output
```
3
```

> - Setiap deklarasi `x = ___` akan menimpa jika ada data dalam variabel tersebut sebelumnya. Dalam code ini, `x = 3` menimpa variabel `x` terakhir kalinya. Maka `print(x)` akan mengeluarkan `3`
